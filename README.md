# EMYRGEN Saudi Climate Intelligence — Executive Website V4

This is a standalone HTML microsite for Saudi executive audiences.

## Open the site
Double-click `index.html` on Windows, macOS or Linux. No build step, installation, internet access, or server is needed for the presentation itself.

## GitHub Pages
1. Create a GitHub repository, e.g. `emyrgen-saudi-climate`.
2. Upload the `index.html` file from this package into the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**, branch **main**, folder **/(root)**, and save.
4. Open the resulting HTTPS link.

The website is public on GitHub Pages. Do not include confidential commercial terms or internal engineering information in a public repo.

## Controls
- Use the navigation for smooth in-page scrolling.
- Click the capability steps and intelligence views.
- Press **F** or click the circle at bottom right for presentation mode. In presentation mode, use left/right arrow keys to move between sections.
- Contact buttons open an email draft (no backend).

## Design
- Typography: Segoe UI Variable Display / Segoe UI and Helvetica Neue / Arial fallback; Georgia italic accent.
- Colors: charcoal, slate, warm stone and champagne gold.
- Four high-resolution, branded titanium-finish EGX-200 mission illustrations embedded into one HTML.
